Agriconnect 🌿
A multi-seller platform connecting farmers and buyers seamlessly.



Overview
Agriconnect is a marketplace that enables farmers to sell their products directly to buyers, eliminating middlemen and improving access to fresh, affordable produce. The platform provides a secure and efficient way for sellers to list their products, manage orders, and receive payments through Paystack.

Features
✅ Multi-seller marketplace for agricultural products
✅ Secure payment processing with Paystack
✅ User-friendly dashboard for buyers and sellers
✅ Order tracking and management system
✅ Mobile-responsive design for easy access
